# sabareishmanokaran.github.io

Site root for [HabitFlow](https://sabareishmanokaran.github.io/habitflow/).

- `.well-known/assetlinks.json` verifies Android App Links, so HabitFlow links open in the
  Android app (`io.github.sabareishmanokaran.habitflow`). The fingerprints are the SHA-256 of
  the app's release signing certificate and of the debug certificate used for test builds.
- `index.html` redirects the bare site to the app.
